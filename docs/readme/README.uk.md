# MyKa's Roblox Spoofer

MyKa's Roblox Spoofer: термінальний застосунок для Windows. У версії 0.3 можна додавати облікові записи Roblox через окремі вікна входу, зберігати підтверджені дані та перевіряти стан системи. Інтерфейс має вкладки Accounts, Diagnostics, Adapters і Identity, керування з клавіатури та обертовий 3D-логотип. Щоб відкрити інструменти ідентифікаторів, натисніть 4, потім Enter або O.

У версії 0.3 клавіша P в Accounts перевіряє обліковий запис у збереженому профілі браузера й відкриває сторінку гри. Запит запуску ще не підтверджує роботу RobloxPlayer та обліковий запис, що приєднався. Команда `identity manage` або S в Adapters відкриває знімки «до/після», порівняння, експорт резервної копії, зміну наявних GUID-рядків і підтримуваних драйвером MAC-параметрів після перегляду плану, оновлення DHCP, очищення DNS та обмежене очищення Roblox. Ці операції не змінюють ідентифікатори прошивки, не створюють незалежні одночасні комп'ютери й не налаштовують нову публічну IP-адресу. Реальні зміни з правами адміністратора ще потрібно перевірити на одноразовій інсталяції Windows. Докладніше англійською: [межі та відновлення](../system-identity.md), [відкриття гри](../desktop-launch.md).

Цей README перекладено українською. Інтерфейс застосунку й команди поки залишаються англійською.

## Що потрібно

Windows x64 і [.NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/download/dotnet/10.0) для готової збірки. Для запуску з вихідного коду потрібен .NET SDK 10. Для входу потрібні [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) та доступ до інтернету.

## Перший запуск

Відкрийте PowerShell у кореневій папці проєкту й запустіть застосунок із вихідного коду:

~~~powershell
dotnet run --project src/MyKa.Spoofer -c Release
~~~

Якщо локальна збірка вже готова, запустіть її так. Залиште всі супровідні файли в одній папці з myka.exe:

~~~powershell
.\.artifacts\publish\myka.exe
.\.artifacts\publish\myka.exe --help
~~~

## Додавання облікового запису

1. На вкладці Accounts натисніть A. Відкриється вікно Roblox з окремим профілем WebView2.
2. Вводьте пароль і коди підтвердження лише на сторінці Roblox. Після входу натисніть Verify account.
3. Застосунок перевірить відповідь `https://users.roblox.com/v1/users/authenticated`. Перевірте ім'я й числовий ID, потім натисніть Save account.

Облікові записи розрізняються за числовим Roblox ID. Повторне додавання того самого запису відхиляється. Для повторного входу створюється новий профіль; інший обліковий запис або скасування не замінюють збережений. Статус `not checked` означає, що чинність сеансу зараз не перевірялася.

## Команди

Додавайте ці команди після `.\.artifacts\publish\myka.exe`. Замість `LOCAL_ACCOUNT_ID` підставте локальний ID з `accounts list`, а не числовий Roblox ID. Додавання, повторний вхід і видалення потребують інтерактивного термінала.

| Команда | Дія |
| --- | --- |
| `accounts list` | Показати збережені облікові записи та локальні ID. |
| `accounts add` | Відкрити вікно входу для нового запису. |
| `accounts login --account LOCAL_ACCOUNT_ID` | Увійти повторно у вибраний запис. |
| `accounts remove --account LOCAL_ACCOUNT_ID` | Підтвердити видалення запису й локального профілю. |
| `accounts cleanup` | Повторити незавершене очищення профілів. |
| `doctor` | Перевірити Windows, .NET, WebView2 і стандартну папку Roblox. |
| `identity inspect` | Показати мережеві адаптери й адреси, які повідомляє Windows. |
| `logo` | Показати логотип. |
| `--help` | Показати довідку про команди. |

## Керування

| Клавіші | Дія |
| --- | --- |
| `← / →, Tab / Shift+Tab, 1-4` | Перемикати вкладки. |
| `↑ / ↓, Home / End, PgUp / PgDn` | Вибирати запис або прокручувати списки та звіти. |
| `A, S / Enter, D / Delete, C` | У Accounts: додати, увійти повторно, видалити, очистити профілі. |
| `R` | Перечитати список або оновити звіт. |
| `F1 / ?, Esc` | Відкрити довідку про клавіші; Esc її закриває. Якщо немає довідки чи підтвердження, Esc або Q завершує роботу. |
| `Space` | Зупинити або відновити обертання логотипа. |
| `Y` | Підтвердити видалення. Будь-яка інша клавіша залишає запис. |
| `Ctrl+C` | Скасувати роботу й вийти з кодом 130. |

Для вкладок потрібне вікно щонайменше 50 стовпців на 12 рядків. `--plain` вмикає нумероване меню без кольору й анімації; `--still` запускає інтерфейс із нерухомим логотипом. Перенаправлення виводу, `NO_COLOR` або `TERM=dumb` також вмикають простий текст.

## Зберігання даних

Дані містяться в `%LOCALAPPDATA%\MyKa\RobloxSpoofer`. Кожен запис має окремий профіль WebView2 з даними сеансу браузера. `accounts.json` містить ID, імена й час перевірки, а не паролі чи cookie. Застосунок не читає cookie або поля форми входу.

Доступ до папки мають поточний користувач Windows, SYSTEM і адміністратори. Метадані замінюються атомарно з копією `.bak`; некоректні дані й невідома версія схеми залишаються без змін. Видалення прибирає локальний профіль, але не завершує сеанси Roblox на інших пристроях.

## Якщо виникли проблеми

- За повідомлення `WebView2 unavailable` установіть або відновіть WebView2 Runtime. Вікно входу дозволяє лише передбачені HTTPS-сторінки Roblox; сторонній вхід із переходом на інші сайти не підтримується.
- Якщо Accounts показує `unavailable`, закрийте інші операції з обліковими записами та натисніть R. Не замінюйте пошкоджений `accounts.json` порожнім файлом.
- Якщо очищення не завершилося, закрийте вікна входу та виконайте `accounts cleanup`. Неповна перевірка `doctor` не означає відсутність Roblox; встановлення зі Store та нестандартні папки не виявляються.

Під час останньої перевірки коду успішно виконано 691 тест. Вхід у справжньому вікні Roblox, перевірки з двома обліковими записами та поведінка в реальних терміналах ще потребують ручної перевірки. Наявність файлів клієнта не підтверджує сумісність або роботу кількох клієнтів.
