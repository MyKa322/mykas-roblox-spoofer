MyKa's Roblox Spoofer: терминальное приложение для Windows. Версия 0.3 позволяет добавлять аккаунты Roblox через отдельные окна входа, сохранять подтверждённые данные аккаунтов и проверять состояние системы. В интерфейсе есть вкладки Accounts, Diagnostics, Adapters и Identity, управление с клавиатуры и вращающийся 3D-логотип. Для доступа к инструментам идентификаторов нажмите 4, затем Enter или O.

В версии 0.3 клавиша P в Accounts открывает страницу игры после проверки аккаунта в сохранённом профиле браузера. Запрос запуска ещё не подтверждает работу RobloxPlayer и аккаунт, вошедший в игру. Команда `identity manage` или S в Adapters открывает снимки «до/после», сравнение, экспорт резервной копии, изменение существующих GUID-строк и поддерживаемых драйвером MAC-настроек после просмотра плана, обновление DHCP, сброс DNS и ограниченную очистку Roblox. Изменение идентификаторов прошивки, отдельные одновременно работающие компьютеры и смена публичного IP этими операциями не обеспечиваются. Реальные изменения с правами администратора ещё нужно проверить на одноразовой установке Windows. Подробности на английском: [область действия и восстановление](../system-identity.md), [запуск игры](../desktop-launch.md).

Этот README переведён на русский. Интерфейс приложения и команды пока остаются на английском.

## Что понадобится

Windows x64 и [.NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/download/dotnet/10.0) для готовой сборки. Для запуска из исходников нужен .NET SDK 10. Вход в аккаунт требует [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) и подключения к интернету.

## Первый запуск

Откройте PowerShell в корневой папке проекта и запустите приложение из исходников:

~~~powershell
dotnet run --project src/MyKa.Spoofer -c Release
~~~

Если локальная сборка уже готова, запустите её так. Файлы рядом с myka.exe должны оставаться в той же папке:

~~~powershell
.\.artifacts\publish\myka.exe
.\.artifacts\publish\myka.exe --help
~~~

## Как добавить аккаунт

1. На вкладке Accounts нажмите A. Откроется окно Roblox с отдельным профилем WebView2.
2. Введите пароль и коды подтверждения только на странице Roblox. После входа нажмите Verify account.
3. Приложение проверит ответ `https://users.roblox.com/v1/users/authenticated`. Проверьте имя и числовой ID, затем нажмите Save account.

Приложение различает аккаунты по числовому Roblox ID. Повторное добавление того же аккаунта отклоняется. При повторном входе используется новый профиль; другой аккаунт или отмена не заменяют сохранённый. Статус `not checked` означает, что приложение сейчас не проверяло действительность сеанса.

## Команды

Добавляйте команды ниже после `.\.artifacts\publish\myka.exe`. Замените `LOCAL_ACCOUNT_ID` локальным ID из `accounts list`, а не числовым Roblox ID. Добавление, повторный вход и удаление требуют интерактивного терминала.

| Команда | Действие |
| --- | --- |
| `accounts list` | Показать сохранённые аккаунты и их локальные ID. |
| `accounts add` | Открыть окно входа для нового аккаунта. |
| `accounts login --account LOCAL_ACCOUNT_ID` | Войти заново в выбранный аккаунт. |
| `accounts remove --account LOCAL_ACCOUNT_ID` | Подтвердить удаление аккаунта и его локального профиля. |
| `accounts cleanup` | Повторить незавершённую очистку профилей. |
| `doctor` | Проверить Windows, .NET, WebView2 и стандартную папку Roblox. |
| `identity inspect` | Показать сетевые адаптеры и адреса, которые сообщает Windows. |
| `logo` | Показать логотип. |
| `--help` | Показать справку по командам. |

## Управление

| Клавиши | Действие |
| --- | --- |
| `← / →, Tab / Shift+Tab, 1-4` | Переключать вкладки. |
| `↑ / ↓, Home / End, PgUp / PgDn` | Выбирать аккаунт или прокручивать список и отчёты. |
| `A, S / Enter, D / Delete, C` | На вкладке Accounts: добавить, войти заново, удалить, очистить профили. |
| `R` | Перечитать список аккаунтов или обновить отчёт. |
| `F1 / ?, Esc` | Открыть справочник клавиш; Esc закрывает его. Без справки или подтверждения Esc либо Q завершает работу. |
| `Space` | Остановить или возобновить вращение логотипа. |
| `Y` | Подтвердить удаление. Любая другая клавиша сохраняет аккаунт. |
| `Ctrl+C` | Отменить работу и выйти с кодом 130. |

Для вкладок нужно окно не меньше 50 столбцов и 12 строк. `--plain` включает нумерованное меню без цвета и анимации; `--still` запускает интерфейс с неподвижным логотипом. При перенаправлении вывода, `NO_COLOR` или `TERM=dumb` приложение использует простой текст.

## Где хранятся данные

Данные находятся в `%LOCALAPPDATA%\MyKa\RobloxSpoofer`. У каждого аккаунта свой профиль WebView2 с данными браузерного сеанса. В `accounts.json` хранятся ID, имена и время проверки, а не пароли или cookie. Приложение не читает cookie и поля формы входа.

Папка доступна текущему пользователю Windows, SYSTEM и администраторам. Метаданные заменяются атомарно с резервной копией `.bak`; некорректные данные или неизвестная версия схемы остаются нетронутыми. Удаление аккаунта убирает локальный профиль, но не завершает сеансы Roblox на других устройствах.

## Если что-то не работает

- При `WebView2 unavailable` установите или восстановите WebView2 Runtime. Окно входа разрешает только предусмотренные HTTPS-страницы Roblox; сторонние способы входа с переходом на другие сайты не поддерживаются.
- Если Accounts показывает `unavailable`, закройте другие операции с аккаунтами и нажмите R. Не создавайте пустой файл вместо повреждённого `accounts.json`.
- Если очистка не завершилась, закройте окна входа и выполните `accounts cleanup`. Неполная проверка `doctor` не означает, что Roblox отсутствует; установки из Store и нестандартные папки эта проверка не обнаруживает.

Последняя проверка кода: успешно пройден 691 тест. Вход через настоящее окно Roblox, проверки с двумя аккаунтами и работа интерфейса в реальных терминалах ещё требуют ручной проверки. Наличие файлов клиента не подтверждает совместимость или работу нескольких клиентов.
