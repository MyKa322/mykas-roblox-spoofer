# MyKa's Roblox Spoofer

[English](../../README.md) | [العربية](README.ar.md) | [Português (Brasil)](README.pt-BR.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Türkçe](README.tr.md) | [Русский](README.ru.md) | [Tiếng Việt](README.vi.md) | [ไทย](README.th.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Українська](README.uk.md) | [Polski](README.pl.md) | [বাংলা](README.bn.md)

MyKa's Roblox Spoofer เป็นแอปสำหรับเทอร์มินัลบน Windows เวอร์ชัน 0.3 ช่วยเพิ่มบัญชี Roblox ผ่านหน้าต่างเข้าสู่ระบบที่แยกจากกัน บันทึกข้อมูลบัญชีที่ยืนยันแล้ว และดูผลการตรวจสอบระบบได้ หน้าจอมีแท็บ Accounts, Diagnostics, Adapters และ Identity รองรับการใช้แป้นพิมพ์ พร้อมโลโก้ 3 มิติที่หมุนได้ กด 4 เพื่อเปิดแท็บ Identity แล้วกด Enter หรือ O เพื่อเปิดเครื่องมือข้อมูลระบุตัวตนของระบบ

ในเวอร์ชัน 0.3 กด P ใน Accounts เพื่อตรวจสอบบัญชีในโปรไฟล์เบราว์เซอร์ที่บันทึกไว้แล้วเปิดหน้าประสบการณ์ คำขอเปิดเกมยังไม่ยืนยันว่า RobloxPlayer ทำงานหรือเข้าร่วมด้วยบัญชีที่ถูกต้อง ใช้ `identity manage` หรือกด S ใน Adapters เพื่อบันทึกค่าก่อนและหลัง เปรียบเทียบ ส่งออกไฟล์สำรอง และตรวจสอบแผนก่อนเปลี่ยนสตริง GUID ที่มีอยู่กับค่า MAC ที่ไดรเวอร์รองรับ รวมถึงต่ออายุ DHCP ล้างแคช DNS และล้างข้อมูล Roblox เฉพาะส่วนที่กำหนด การแก้ตัวระบุเฟิร์มแวร์ การสร้างคอมพิวเตอร์อิสระที่ทำงานพร้อมกัน และการกำหนด IP สาธารณะใหม่ไม่อยู่ในขอบเขตนี้ การเปลี่ยนค่าจริงด้วยสิทธิ์ผู้ดูแลยังต้องทดสอบบน Windows ที่พร้อมทิ้งได้ ดูคู่มือภาษาอังกฤษเรื่อง[ขอบเขตและการกู้คืน](../system-identity.md) และ[การเปิดประสบการณ์](../desktop-launch.md)

README นี้เป็นภาษาไทย ส่วนหน้าจอแอปและคำสั่งยังเป็นภาษาอังกฤษ

## สิ่งที่ต้องมี

แอปที่คอมไพล์แล้วต้องใช้ Windows x64 และ [.NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/download/dotnet/10.0) หากรันจากซอร์สโค้ด ให้ใช้ .NET SDK 10 การเข้าสู่บัญชีต้องมี [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) และการเชื่อมต่ออินเทอร์เน็ตด้วย

## เริ่มใช้งาน

เปิด PowerShell ในโฟลเดอร์รากของโปรเจกต์ แล้วรันแอปจากซอร์สโค้ด:

~~~powershell
dotnet run --project src/MyKa.Spoofer -c Release
~~~

หากมีไฟล์ที่บิลด์ไว้ในเครื่องแล้ว ให้รันคำสั่งต่อไปนี้ เก็บไฟล์ประกอบทั้งหมดไว้ในโฟลเดอร์เดียวกับ myka.exe:

~~~powershell
.\.artifacts\publish\myka.exe
.\.artifacts\publish\myka.exe --help
~~~

## เพิ่มบัญชี

1. กด A ในแท็บ Accounts เพื่อเปิดหน้าต่าง Roblox ที่ใช้โปรไฟล์ WebView2 แยกต่างหาก
2. กรอกรหัสผ่านและรหัสยืนยันเฉพาะบนหน้า Roblox หลังเข้าสู่ระบบแล้ว กด Verify account
3. แอปจะตรวจสอบคำตอบจาก `https://users.roblox.com/v1/users/authenticated` ตรวจสอบชื่อและ ID ตัวเลข แล้วกด Save account

แอปแยกบัญชีด้วย ID ตัวเลขของ Roblox และไม่อนุญาตให้บันทึกบัญชีเดิมซ้ำ การเข้าสู่ระบบใหม่จะใช้โปรไฟล์ใหม่ หากเข้าสู่บัญชีอื่นหรือยกเลิก แอปจะไม่แทนที่บัญชีที่บันทึกไว้ สถานะ `not checked` หมายความว่ายังไม่ได้ตรวจสอบว่าเซสชันปัจจุบันใช้งานได้อยู่หรือไม่

## คำสั่ง

เพิ่มคำสั่งด้านล่างต่อท้าย `.\.artifacts\publish\myka.exe` แทนที่ `LOCAL_ACCOUNT_ID` ด้วย ID ภายในแอปจาก `accounts list` ไม่ใช่ ID ตัวเลขของ Roblox การเพิ่ม เข้าสู่ระบบใหม่ และลบบัญชีต้องใช้เทอร์มินัลแบบโต้ตอบ

| คำสั่ง | การทำงาน |
| --- | --- |
| `accounts list` | แสดงบัญชีที่บันทึกไว้และ ID ภายในแอป |
| `accounts add` | เปิดหน้าต่างเข้าสู่ระบบสำหรับบัญชีใหม่ |
| `accounts login --account LOCAL_ACCOUNT_ID` | เข้าสู่ระบบบัญชีที่เลือกอีกครั้ง |
| `accounts remove --account LOCAL_ACCOUNT_ID` | ขอให้ยืนยันการลบบัญชีและโปรไฟล์ในเครื่อง |
| `accounts cleanup` | ลองล้างโปรไฟล์ที่ยังค้างอยู่อีกครั้ง |
| `doctor` | ตรวจสอบ Windows, .NET, WebView2 และโฟลเดอร์ติดตั้ง Roblox ตามค่าเริ่มต้น |
| `identity inspect` | แสดงอะแดปเตอร์เครือข่ายและที่อยู่ที่ Windows รายงาน |
| `logo` | แสดงโลโก้ |
| `--help` | แสดงวิธีใช้คำสั่ง |

## การเก็บข้อมูล

ข้อมูลอยู่ที่ `%LOCALAPPDATA%\MyKa\RobloxSpoofer` แต่ละบัญชีมีโปรไฟล์ WebView2 ของตนเองซึ่งเก็บข้อมูลเซสชันเบราว์เซอร์ `accounts.json` เก็บ ID ชื่อ และเวลาที่ตรวจสอบ ไม่เก็บรหัสผ่านหรือคุกกี้ แอปไม่อ่านคุกกี้หรือช่องกรอกข้อมูลในแบบฟอร์มเข้าสู่ระบบ

โฟลเดอร์อนุญาตให้ผู้ใช้ Windows ปัจจุบัน SYSTEM และผู้ดูแลระบบเข้าถึงได้ แอปแทนที่ข้อมูลเมตาแบบอะตอมมิกและเก็บสำเนา `.bak` ข้อมูลที่ไม่ถูกต้องหรือมีรุ่นโครงสร้างที่ไม่รู้จักจะไม่ถูกแก้ไข การลบบัญชีจะลบโปรไฟล์ในเครื่อง แต่ไม่ยุติเซสชัน Roblox บนอุปกรณ์อื่น

## เมื่อพบปัญหา

- หากเห็น `WebView2 unavailable` ให้ติดตั้งหรือซ่อมแซม WebView2 Runtime หน้าต่างเข้าสู่ระบบอนุญาตเฉพาะหน้า HTTPS ของ Roblox ที่กำหนดไว้ จึงไม่รองรับการเข้าสู่ระบบผ่านผู้ให้บริการอื่นที่เปลี่ยนไปยังเว็บไซต์ภายนอก
- หาก Accounts แสดง `unavailable` ให้ปิดการดำเนินการเกี่ยวกับบัญชีอื่น แล้วกด R อย่าเขียนไฟล์เปล่าทับ `accounts.json` ที่เสียหาย
- หากล้างโปรไฟล์ไม่เสร็จ ให้ปิดหน้าต่างเข้าสู่ระบบแล้วรัน `accounts cleanup` ผลตรวจ `doctor` ที่ไม่ครบถ้วนไม่ได้หมายความว่าไม่ได้ติดตั้ง Roblox การตรวจนี้ไม่พบการติดตั้งจาก Store หรือโฟลเดอร์ที่ต่างจากค่าเริ่มต้น

การตรวจสอบโค้ดล่าสุดผ่านการทดสอบ 691 รายการ ส่วนการเข้าสู่ระบบผ่านหน้าต่าง Roblox จริง การใช้สองบัญชี และพฤติกรรมในเทอร์มินัลจริงยังต้องตรวจสอบด้วยตนเอง การพบไฟล์ไคลเอนต์ไม่ได้ยืนยันความเข้ากันได้หรือการรันหลายไคลเอนต์พร้อมกัน
