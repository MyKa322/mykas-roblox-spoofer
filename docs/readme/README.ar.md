في الإصدار 0.3، يفتح المفتاح P في Accounts صفحة تجربة بالحساب المحفوظ بعد التحقق من هوية المتصفح. طلب التشغيل لا يؤكد أن RobloxPlayer عمل أو انضم بالحساب الصحيح. يفتح `identity manage`، أو S في Adapters، نافذة القيم قبل التغيير وبعده، والمقارنة والنسخ الاحتياطي، وتغييرات GUID المخزنة وMAC المدعومة من برنامج التشغيل، وتجديد DHCP ومسح DNS والتنظيف المحدد. لا تتضمن هذه الأدوات تغيير معرّفات البرنامج الثابت أو إنشاء أجهزة مستقلة أو توجيه عنوان IP عام جديد. العمليات التي تتطلب صلاحيات المدير لم تُختبر على النظام الحقيقي. [النطاق والاستعادة](../system-identity.md) و[طلب التشغيل](../desktop-launch.md) بالإنجليزية.

تطبيق MyKa لسطح Windows يضم علامات التبويب Accounts وDiagnostics وAdapters وIdentity، مع إدارة الحسابات وأدوات النظام وشعار ثلاثي الأبعاد. للوصول مباشرة إلى أدوات الهوية، اضغط 4 لفتح Identity ثم Enter أو O.

هذا README باللغة العربية. واجهة التطبيق والأوامر ما زالت باللغة الإنجليزية.

## المتطلبات

لتشغيل النسخة المبنية، تحتاج إلى Windows x64 و[.NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/download/dotnet/10.0). وللتشغيل من الشيفرة المصدرية، استخدم .NET SDK 10. يتطلب تسجيل الدخول أيضًا [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) واتصالًا بالإنترنت.

## التشغيل الأول

افتح PowerShell في المجلد الرئيسي للمشروع، ثم شغّل التطبيق من الشيفرة المصدرية:

<div dir="ltr">

~~~powershell
dotnet run --project src/MyKa.Spoofer -c Release
~~~

</div>

<div dir="ltr">

~~~powershell
.\.artifacts\publish\myka.exe
.\.artifacts\publish\myka.exe --help
~~~

## إضافة حساب

1. اضغط A في علامة التبويب Accounts. ستفتح نافذة Roblox بملف تعريف WebView2 خاص بها.
2. أدخل كلمة المرور ورموز التحقق في صفحة Roblox فقط. بعد تسجيل الدخول، اضغط Verify account.
3. يفحص التطبيق الاستجابة من `https://users.roblox.com/v1/users/authenticated`. راجع الاسم والمعرّف الرقمي، ثم اضغط Save account.

يميّز التطبيق الحسابات باستخدام معرّف Roblox الرقمي، ولا يسمح بحفظ الحساب نفسه مرتين. تستخدم إعادة تسجيل الدخول ملف تعريف جديدًا؛ الدخول إلى حساب مختلف أو إلغاء العملية لا يستبدل الحساب المحفوظ. تعني الحالة `not checked` أن صلاحية الجلسة الحالية لم تُفحص في تلك اللحظة.

## الأوامر

أضف هذه الأوامر بعد `.\.artifacts\publish\myka.exe`. استبدل `LOCAL_ACCOUNT_ID` بالمعرّف المحلي الذي يعرضه `accounts list`، وليس بمعرّف Roblox الرقمي. تتطلب الإضافة وإعادة تسجيل الدخول والحذف طرفية تفاعلية.

| الأمر | وظيفته |
| --- | --- |
| `accounts list` | يعرض الحسابات المحفوظة ومعرّفاتها المحلية. |
| `accounts add` | يفتح نافذة تسجيل الدخول لحساب جديد. |
| `accounts login --account LOCAL_ACCOUNT_ID` | يسجّل الدخول مجددًا إلى الحساب المحدد. |
| `accounts remove --account LOCAL_ACCOUNT_ID` | يطلب تأكيد حذف الحساب وملف تعريفه المحلي. |
| `accounts cleanup` | يعيد محاولة تنظيف ملفات التعريف التي لم يكتمل حذفها. |
| `doctor` | يفحص Windows و.NET وWebView2 ومجلد تثبيت Roblox الافتراضي. |
| `identity inspect` | يعرض محوّلات الشبكة والعناوين التي يبلّغ عنها Windows. |
| `logo` | يعرض الشعار. |
| `--help` | يعرض مساعدة الأوامر. |

## التحكم بلوحة المفاتيح

| المفاتيح | الإجراء |
| --- | --- |
| `← / →, Tab / Shift+Tab, 1-4` | التنقل بين علامات التبويب. |
| `↑ / ↓, Home / End, PgUp / PgDn` | اختيار حساب أو تمرير القوائم والتقارير. |
| `A, S / Enter, D / Delete, C` | في Accounts: الإضافة، وإعادة تسجيل الدخول، والحذف، وتنظيف ملفات التعريف، بالترتيب. |
| `R` | إعادة تحميل قائمة الحسابات أو تحديث التقرير. |
| `F1 / ?, Esc` | فتح دليل المفاتيح؛ يغلقه Esc. عند عدم وجود دليل أو طلب تأكيد مفتوح، ينهي Esc أو Q التطبيق. |

تحتاج واجهة علامات التبويب إلى نافذة بعرض 50 عمودًا وارتفاع 12 سطرًا على الأقل. يستخدم `--plain` قائمة مرقمة دون ألوان أو حركة، ويبدأ `--still` بشعار ثابت. يُستخدم النص البسيط أيضًا عند إعادة توجيه المخرجات أو ضبط `NO_COLOR` أو `TERM=dumb`.

## البيانات المحفوظة

توجد البيانات في `%LOCALAPPDATA%\MyKa\RobloxSpoofer`. لكل حساب ملف تعريف WebView2 منفصل يحتوي على بيانات جلسة المتصفح. يحفظ `accounts.json` المعرّفات والأسماء وأوقات التحقق، ولا يحفظ كلمات المرور أو ملفات تعريف الارتباط. لا يقرأ التطبيق ملفات تعريف الارتباط أو حقول نموذج تسجيل الدخول.

يمكن لمستخدم Windows الحالي وSYSTEM والمسؤولين الوصول إلى المجلد. تُستبدل البيانات الوصفية بعملية ذرية مع الاحتفاظ بنسخة `.bak`؛ وتبقى البيانات غير الصالحة أو ذات إصدار البنية غير المعروف دون تغيير. حذف الحساب يزيل ملف تعريفه المحلي، لكنه لا ينهي جلسات Roblox على الأجهزة الأخرى.

## عند حدوث مشكلة

- إذا ظهر `WebView2 unavailable`، ثبّت WebView2 Runtime أو أصلح تثبيته. تسمح نافذة الدخول بصفحات Roblox المحددة عبر HTTPS فقط. طرق الدخول عبر مزوّدين آخرين التي تنقلك إلى مواقع خارجية غير مدعومة.
- إذا عرضت Accounts الحالة `unavailable`، أغلق عمليات الحسابات الأخرى ثم اضغط R. لا تستبدل ملف `accounts.json` التالف بملف فارغ.
- إذا بقي التنظيف غير مكتمل، أغلق نوافذ تسجيل الدخول وشغّل `accounts cleanup`. فحص `doctor` غير المكتمل لا يثبت غياب Roblox. لا يكشف الفحص التثبيت من Store أو مجلدات التثبيت غير الافتراضية.

نجح 691 اختبارًا في آخر فحص للشيفرة. ما زال تسجيل الدخول في نافذة Roblox الفعلية، وتجربة حسابين، وسلوك الواجهة في الطرفيات الحقيقية بحاجة إلى فحص يدوي. وجود ملفات العميل لا يؤكد التوافق أو إمكانية تشغيل عدة عملاء معًا.
