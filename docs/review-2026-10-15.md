# Code review — 2026-10-15

Reviewed the current tabbed interface, account operations, storage, authentication boundary, diagnostics, and build output. This directory has no Git history, so this is a review of the current files rather than a branch diff. The tabbed design and 3D renderer were preserved.

## Findings addressed

| Priority | Finding | Resolution |
| --- | --- | --- |
| High | An undersized terminal displayed only a resize notice but still dispatched account actions, including removal confirmation. A pending modal could also swallow the advertised Esc-to-quit key. | Check resize before consuming input. While too small, accept only quit keys and never dispatch to pages. |
| Medium | The loop consumed all queued keys before redrawing. A queued D then Y could remove an account without displaying the question. | Consume one key per frame so the confirmation is drawn before its answer is processed. |
| Medium | Metadata loading rejected files over 1 MiB, but saving had no matching limit. A valid compact document could be rewritten into an unreadable larger document. | Check serialized size before atomic replacement; preserve the previous file and in-memory state and remove the temporary file. |
| Medium | The fallback selection prompt stripped control characters but interpreted brackets in titles and choices as Spectre markup. | Escape markup after sanitizing prompt text. |
| Low | The WebView2 package added an unused WPF reference to the WinForms application and tests, producing a WindowsBase assembly conflict. | Remove only that unused reference before assembly resolution, with no warning suppression. |
| Low | The README and terminal specification still described the old home menu and report pauses. | Document tabs, shortcuts, modal removal, actual layout thresholds, fallback navigation, and implementation ownership. |

## Design usability follow-up

The next design pass keeps the existing palette and 3D wordmark and improves the tabbed interaction:

- Shortens the runtime status and Adapters tab label, and uses compact action hints so help, motion, quit, and account actions remain readable at 50×12.
- Adds F1 / `?` for a scrollable shortcut guide. It contains page input and returns to the same selection and feedback; Esc closes help before quitting.
- Adds Space to pause/resume logo motion during the session. `--still` sets the initial preference, help automatically stays still, and hidden or paused logos do not cause idle redraws.
- Adds R to reload accounts. Failed reads now show an explicit unavailable state with scrollable error details and retry, with account actions inactive until a successful read.
- Keeps both the account name and full numeric Roblox ID visible in the minimum-height removal prompt. Sign-in progress says “Opening” before the browser starts.
